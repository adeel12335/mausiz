# Maurizio Dècina — homepage concept

Visual mockups for review before website implementation.

## Direction

A refined academic website with true white, midnight navy (#10263D), muted slate (#647080), gold (#B59148), pale blue-gray portrait backgrounds (#EEF2F5), elegant serif headings and clean readable interface text. Open layouts and fine rules replace repetitive boxed cards. The portrait comes from the existing website.

## Page order

1. Header, introduction and affiliations.
2. Research, leadership and service; career milestones.
3. Four research areas and a mission statement.
4. Publications, teaching archive, recognition and contact footer.

A separate mobile concept shows the opening view as a responsive layout.

## Content choices

English follows the supplied PDF. Preserve the name spelling Maurizio Dècina. Real publication titles and dated milestones come from the existing website. Contact uses maurizio@mauriziodecina.it. The unverified example publication titles and 2024 honour from the PDF have been replaced with documented archive material. The mission statement is proposed editorial copy, not a verbatim quotation by Maurizio.
